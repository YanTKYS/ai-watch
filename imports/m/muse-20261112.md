## 1. 分析作業は、「定期実行・イベント駆動で回る自律型コワーカー」に任せる型にする

- 分野: 調査・分析
- 何を楽にするのか: 分析の依頼から資料作りまでの周辺作業（変化の監視、不足情報の催促、定期レポートの更新）を、人がその都度指示しなくても回るようにする。
- 再現の仕組み: Databricks の新しい Genie（2026-11-11発表）の型を参考にする。分析の土台として「Genie Ontology」（業務用語・指標・権限の意味づけ層）を一般提供で整え、どの数字が何を指すかを組織で共有する。Genie は定期実行やイベント駆動で動き、複数の仕事を並行して進め、必要な操作には人の承認を挟む。文書（PDF・スライド）も表と並べて分析し、ページ単位の引用を付けて返す。検索対象は Google Drive・Jira・Confluence・Workday へ広がっており、SharePoint はベータ。成果物は Genie One という画面でスライド・ダッシュボード・対話ページとして作り、定期更新と再利用できる「スキル」を共有する。General Motors では1,000超の Genie エージェントが営業・開発・サプライチェーン・人事で動いているとされる。なお Genie One は2027-01-31まで無料とされるが、その後の料金体系は未発表のため、導入は提供条件を確認してから進める。
- 何が新しくなったか: 分析AIが「聞かれたら答える」形から、「変化を監視し、不足を催促し、定期的に回す」自律型の同僚へ進んだ。Turing と共同開発したベンチマークでは Genie が91%のタスク実行に成功したとされるが、Databricks 自身が「蓄積された業務知識のある既存導入環境での結果」と注記しており、新規導入では差が小さくなる可能性がある。
- 出典: https://www.unite.ai/databricks-turns-genie-into-an-autonomous-enterprise-ai-coworker/

## 2. エージェントの全社展開は、「6,000の既製エージェント＋業界枠組み」から始める型にする

- 分野: 開発・導入
- 何を楽にするのか: 業務ごとにエージェントを一から作る手間を省き、既製の部品と業界別の枠組みから全社展開を始める。
- 再現の仕組み: IBM と Microsoft の Imagine Enterprise（2026-11-10発表）の型を参考にする。IBM Consulting の6,000超の既製エージェントと資産を種にして、金融・保険・小売の業界枠組みから始める。製造・エネルギー・公共・モビリティは次の対象とされている。基盤は Microsoft 側の Foundry・GitHub Copilot・Copilot Studio・Fabric・Microsoft 365・Entra・Purview・Defender・Azure で、IBM 側は Process Studio・Context Studio・Advantage Core で業界固有の道具を重ねる。統制・可観測性・AIコンプライアンスを売りにしており、初期顧客として資産約2兆ドルを管理する SEI が名乗りを上げている。なお発表では価格・追加のパイロット顧客・製造や公共向け枠組みの時期は示されておらず、監査向けに個々のエージェントの行動記録をどう残すかも説明されていないため、導入検討ではこの点を先に確認する。
- 何が新しくなったか: エージェント導入が「1業務ずつの実証」から「業界別の枠組みと数千の既製部品を束ねた基盤」へ進んだ。McKinsey の調査では少なくとも1つの業務機能でエージェントを拡大中の大企業が40%（前回27%）に増えたとされ、基盤整備の遅れが課題になっている。
- 出典: https://www.technologyrecord.com/article/ibm-and-microsoft-launch-imagine-enterprise

## 3. BIの問い合わせは、「意味層とオントロジーを共有するマルチエージェント」に渡す型にする

- 分野: 調査・分析
- 何を楽にするのか: 数字の定義が人によって違うまま AI に聞く状態をやめ、組織のデータの意味を共有したうえで、分析・可視化・SQL生成までを分業で進める。
- 再現の仕組み: Zoho Analytics の Agentic Analytics 化（2026-11-10発表）の型を参考にする。データの構造・意味・関係を「セマンティック層」と「オントロジー」として組織のデータに合わせて作り、AIがその意味づけの上で動く。会話型の Ask Zia は、中央のエージェントが計画・調整し、データ分析・可視化・データ準備・モデリング・コーディング・SQL生成の6つの専門サブエージェントが同じ意味層と会話履歴・記憶を共有して動く。組織は Zia 自身の LLM を使うか、持ち込みのフロンティアモデルを選べる。特定の用途には同じ意味層と知識ベースに根ざした独自のデータエージェントを作る。クラウド版は提供開始済みで、ピクセル単位の帳票・オントロジー・セマンティックモデルのプレビューは今後4〜8週間で世界展開、オンプレミス版は2027年第1四半期予定。料金は据え置きで、各プランに Zoho LLM クレジットが含まれる。
- 何が新しくなったか: BI の AI が「1つのチャットが何でも答える」形から、「意味層を共有した専門エージェント群が分業する」形へ進んだ。定義の食い違いによる誤った数字を減らす仕組みが、分析の土台として組み込まれた。
- 出典: https://www.malaymail.com/news/money/mediaoutreach/2026/11/10/zoho-brings-trusted-business-intelligence-to-ai-agents-in-zoho-analytics-platform-evolution-connecting-data-business-context-insights-and-action/499886

## 4. 顧客との出会いは、「ChatGPT内に認証済みの自社窓口を持つ」型にする

- 分野: マーケティング・営業
- 何を楽にするのか: ChatGPT の中で自社がどう紹介されるかを他人任せにせず、情報の正確さと顧客との接点を自社で管理できるようにする。
- 再現の仕組み: OpenAI の Businesses in ChatGPT（2026-11-10にベータ開始）の型を参考にする。ChatGPT のサイドバーにある Business Hub で自社を申請し、本人確認を経て青いチェック付きのプロフィールを持つ。ウェブサイト・説明・ロゴ・配送や返品の方針を更新し、価格と在庫の入った商品フィードをセルフサービスで追加する。Business Hub には過去28日間の言及回数・サイト訪問・発見トピックといった集計データが表示され、ユーザーの会話内容は事業者と共有されないとされる。対象は米国の適格な EC・オンラインサービス事業者で、自社の商品情報と方針を元に顧客の質問に答える Business Agent を作れる。エージェントとの会話は ChatGPT 本体の回答とは別の、表示付きの会話になる。Business Agent は ChatGPT 広告の行き先としてスポンサーすることもできる。なお現時点では無料と報じられているが、将来の課金は否定されておらず、プロフィールの申請が ChatGPT での表示順位や売上を保証するものではないと OpenAI は明言している。Business Agent は当面米国限定のため、日本の事業者はまずプロフィールの申請と商品フィードの整備から始める。
- 何が新しくなったか: 企業が AI チャットの中で「紹介される側」から「認証済みの窓口を持つ側」へ進んだ。検索エンジンでの Google ビジネスプロフィールに相当する仕組みが、ChatGPT の中にもできた。
- 出典: https://www.superpowerdaily.com/posts/openai-lets-businesses-manage-chatgpt-profiles-and-launch-customer-facing-agents

## 5. 長期の難題は、「最強モデルを検証の回る仕事にだけ当てる」型にする

- 分野: 開発
- 何を楽にするのか: 複雑なコーディング・デバッグ・科学研究など、長い推論と繰り返しの検証が必要な仕事で、モデルを用途別に使い分ける。
- 再現の仕組み: Google の Gemini 4 Carbon（2026-11-10に一般提供開始）の型を参考にする。Carbon は Gemini 4 Argon を土台に、推論と検証をより多く回す設計で、Google はサイバーセキュリティと長期の AI ワークフローで最強のモデルと位置づける。用途の分け方は、ふだんのソフトウェア開発や知識労働は Argon、複雑なコーディング・デバッグ・科学研究や多段階の金融調査は Carbon とする。利用経路は、有料の Gemini API（Google AI Studio）と Gemini for business で、モデル名は gemini-4-carbon。料金は2026-11-30まで入力100万トークンあたり2ドル・出力100万トークンあたり10ドルで、2026-12-01から4ドル・20ドルに上がる（Argon と同じ）。Google AI Ultra の加入者には Gemini アプリ・検索の AI モード・Antigravity でも順次提供される。Antigravity では複雑なプロジェクト向けに「/swarm」という機能もプレビューされている。なお Gemini アプリ側では Carbon は Ultra 限定で、Google AI Plus では使えない。発表前の限定提供はサイバー防衛者向けの Fairwind プログラムだった。
- 何が新しくなったか: Gemini 4 の最上位モデルが、限られた防衛者向けから有料開発者・企業・Ultra 加入者へ広がった。CursorBench 4.0 などで1位とされるが、これらは Google の発表値で、導入時は自社の課題で試してから使い分ける。
- 出典: https://economictimes.indiatimes.com/tech/artificial-intelligence/gemini-4-carbon-opens-to-developers-enterprises-with-advanced-ai-capabilities-for-complex-tasks/articleshow/135724889.cms

## 6. 医療の事務作業は、「読み取り専用で記録とつなぐ業界特化エージェント」に任せる型にする

- 分野: 医療・事務
- 何を楽にするのか: 医師・看護師の週28時間近くにのぼるとされる書類・事務作業を、診療記録と保険手続きをつなぐ形で減らす。
- 再現の仕組み: Google Cloud の Gemini for healthcare（2026-11-10に米国でプレビュー開始）の型を参考にする。10月に発表した汎用の Gemini エージェントに、医療向けの指示と既存システムへの接続を加える。Epic と Oracle Health の電子カルテからは open.epic API と FHIR 用の Ignite API で読み取り専用で情報を取り、書き戻しはしない。受診前の準備、患者の既往歴の整理、保険の事前承認に必要な書類の作成といった多段階の作業を進める。NextGen Healthcare への接続は今後数か月で追加予定。HIPAA への対応をうたう。対象は Gemini Enterprise Standard・Plus の米国の顧客で、定額の席単位か従量課金のどちらかで提供される。開始時の顧客として HCA Healthcare・Highmark Health・Northwell Health などが名乗りを上げている。なお価格・一般提供の時期は未発表で、日本での提供も未定。Epic 側の接続には、1回の検索は1人の患者のみ、PDF 文書は読めない、長い記録は途中で切れるといった制限があるとされる。
- 何が新しくなったか: 汎用エージェントに業界特化の接続と指示を重ねる「業界版エージェント」が、政府・金融・法務に続いて医療へ広がった。記録への書き込みを禁じる読み取り専用の設計が、医療現場での導入の型になっている。
- 出典: https://www.fiercehealthcare.com/ai-and-machine-learning/google-cloud-rolls-out-gemini-healthcare

## 7. 音声の顧客対応は、「現場の会話から自社モデルを育てる」型にする

- 分野: サポート・議事録
- 何を楽にするのか: 音声・チャットの顧客対応と社内の会議記録を、汎用モデルのまま使うのではなく、自社の現場の会話から育てた仕組みで回す。
- 再現の仕組み: ElevenLabs の発表（2026-11-11、ニューヨークサミット）の型を参考にする。実運用の会話データを使って、選んだオープンソースの言語モデルと音声モデルを自社向けに微調整する。会話の進め方を決める Interaction Engine のプレビューもあり、相手や状況に応じて対話の流れを変える。ElevenAgents には Memory（顧客や会話の記憶）と Routines（会話と業務システムをつなぐ定型の動き）が加わる。社員向けには ElevenAI というアプリがあり、対面の会議を含む話し言葉の会話を聞き、メモ・要約・アクションアイテムを作る。早期アクセスは無料で開始されている。導入の型としては、まず医療向けの文字起こしモデル Scribe v3 Medical のように、業界用語を覚えさせた専用モデルから試す。NVIDIA との連携で Nemotron 3.5 Super VL が ElevenAgents で使えるようになり、オンプレミスの音声エージェント（ポーランドの国民 e-Health の中央予約システム向け）も進んでいる。なおモデルの微調整の提供は今後数か月で始まる予定で、詳細な料金は未発表。
- 何が新しくなったか: 音声 AI が「声を作る・文字に起こす」道具から、「現場の会話でモデルを育て、記憶と定型の動きで回す」業務基盤へ進んだ。会話エージェントをクラウドや決済と同じ「重要インフラ」と位置づける発言もあった。
- 出典: https://www.unite.ai/elevenlabs-unveils-model-customization-elevenai-and-partner-program/

## 8. 遺伝子研究は、「細胞タイプごとの影響を予測する専用モデル」を使う型にする

- 分野: 研究・ライフサイエンス
- 何を楽にするのか: DNA の変異が遺伝子の働きに与える影響を、細胞の種類ごとに予測する手間を減らす。
- 再現の仕組み: Google DeepMind の AlphaGenome 2（2026-11-12発表）の型を参考にする。100万以上の細胞プロファイルで68の組織を学習したモデルを使い、特定の細胞タイプで DNA 変異が遺伝子発現にどう影響するかを予測する。以前のモデルと比べて約2倍の変異を特定できるとされる。細胞の状態に応じたゼロショット適応もでき、疾患研究での利用が想定されている。非商業の研究向けに API と Colab チュートリアルで発表当日から利用できる。利用の型としては、まず Colab チュートリアルで自社の変異データを試し、予測の当たり方を確認してから研究の本流に組み込む。
- 何が新しくなったか: ゲノム AI が「変異があるかどうか」から「どの細胞で、遺伝子の働きにどう影響するか」を予測する段階へ進んだ。細胞タイプ特異的な予測が、API 経由で研究者の手元に届くようになった。
- 出典: https://x.com/GoogleDeepMind/status/2120532824465805749

## 9. 会議の文字起こしは、「アジェンダの用語を先に渡して精度を上げる」型にする

- 分野: 議事録
- 何を楽にするのか: 会議のリアルタイム文字起こしで、話者名や専門用語の聞き間違いを減らす。
- 再現の仕組み: Mistral AI の Voxtral Transcribe 3（2026-11-11、AI Engineer Paris で実演）の型を参考にする。会議のアジェンダから話者名や技術用語を「コンテキストバイアス」としてモデルに先に渡し、実際の会議の音声をリアルタイムで文字に起こす。実演ではメインステージの全講演をその場で文字起こしした。運用の型としては、会議前にアジェンダ・参加者名・専門用語の一覧を1枚の資料にまとめ、それを文字起こしの事前情報として渡す手順を定型化する。議事録の要約そのものは使い古された一般論だが、ここでは「事前に用語を渡して聞き取り精度を上げる」という再現可能な手順が新しい点になる。
- 何が新しくなったか: リアルタイムの文字起こしが、モデルの性能そのものではなく「会議の文脈を先に与える」工夫で実務の精度に届く段階に入った。実際の会議環境での実演で、話者名や技術用語の聞き間違いを抑えられることが示された。
- 出典: https://x.com/MistralAI/status/2120489851615084876

## 10. モーション制作は、「エージェントから呼べるヘッドレスのモーションエンジン」を使う型にする

- 分野: デザイン・資料作成
- 何を楽にするのか: 動画やアニメーションの制作を、デザインツールを開いて手で操作する作業から、コーディングエージェントが指示で動かす作業へ変える。
- 再現の仕組み: LottieFiles の Creator MCP（2026-11-11公開）の型を参考にする。モーションエンジンを MCP（Model Context Protocol）経由で公開し、Claude・Cursor・Codex などのエージェントから直接操作できるようにする。ヘッドレスで高速に動き、文脈のある場所（エージェントがコードや資料を扱っている場）で実行できる。運用の型としては、資料やアプリの制作フローに「モーション生成」の手順を1工程として組み込み、エージェントへの指示文と出力の置き場所を固定しておく。Lottie 形式の利点として、軽量なベクターベースのアニメーションをアプリや Web にそのまま載せられる。
- 何が新しくなったか: デザイン・モーションツールが、人が操作するアプリから「エージェントが MCP 経由で呼ぶ部品」へ進んだ。コーディングエージェントの作業範囲に、動画・モーションの生成が直接入るようになった。
- 出典: https://x.com/LottieFiles/status/2120335987125743912
